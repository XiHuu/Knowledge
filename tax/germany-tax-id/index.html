    德国税号：010250 表到底是什么，人在国内能不能用¶

    来源：德国联邦财政部表单系统（formulare-bfinv.de，010250，Stand 02/2026）、 BZSt（联邦中央税务局）FAQ、柏林服务门户 / 科隆大学 / 萨克森 / 巴伐利亚财政局官方说明、 BMF-Schreiben vom 16.07.2026（境外企业增值税登记新表样）。整理时间 2026-10。

    先说结论¶

    010250 不是「德国税务登记表」，它是「为不在德国户籍登记的人核发个人税号（IdNr）」的申请表。 而且它有硬前提：你必须和德国存在税务连接点。人在国内、完全不在德国活动，这张表递上去会被退回。

    中文圈里常把"德国税务登记表"和 010250 混称，其实完全不是一张表 —— 那张企业用的叫 Fragebogen zur steuerlichen Erfassung，编号 034250，而且必须走 ELSTER 电子提交。

    德国的三个「税号」，先分清¶

    号码 德文 谁发 形态 用途 怎么拿到
    个人税号 Steuerliche Identifikationsnummer（IdNr / Steuer-ID） BZSt（有德国户籍者自动发放）／ 当地 Finanzamt（非登记人员） 11 位纯数字，终身不变 个人所得税、雇主代扣（ELStAM）、报税身份标识 ①在德落户 → 自动寄到户籍地址 ②交德国个税申报 → 税务局随申报分配 ③提交 010250
    税号 Steuernummer 当地 Finanzamt 10–13 位，通常带 / 企业开票、VAT 申报 Fragebogen zur steuerlichen Erfassung（必须 ELSTER，§ 138 Abs. 1b AO）
    增值税号 Umsatzsteuer-Identifikationsnummer（USt-IdNr） BZSt DE + 9 位 欧盟内 B2B 跨境交易免税 完成增值税登记、税务局把数据转给 BZSt 后才能发

    一句话记住：IdNr 是「人」的，Steuernummer 是「税局给你的档案号」，USt-IdNr 是「欧盟内做生意用的」。

    010250 的准入门槛¶

    柏林服务门户列的条件是两条必须同时满足：

    1. 在德国没有户籍登记义务（没有住所、没有固定居所）
    2. 并且存在德国纳税义务，或在德国从事非独立劳动

    官方点名的适用人群：

    • 在德国工作但住在国外的人（雇员、季节工、短期雇员 / 实习生 / 学生）
    • 在德国负有（可能是有限的）个人所得税义务的自雇者、营业者、出租人

    🔴 反过来读：如果你既不在德国工作、也没有德国来源所得、也不是德国纳税人， 第 2 条不成立 —— 010250 没有适用场景。

    （BZSt 自己的 FAQ 里有个同构的例子：住在国外的孩子因为在德国不纳税，所以不发 IdNr。）

    人在国内的实操：怎么填、寄给谁¶

    表从哪来¶

    https://www.formulare-bfinv.de/ → 搜索框输 010250。 这是仍在用 PDF / 纸质流程的少数表之一，可以下载、填写、签字、邮寄。

    寄给谁（最常见的退回原因就是寄错税局）¶

    你的身份 受理机关
    受雇于德国雇主 雇主的 Betriebsstättenfinanzamt（雇主所在地税局）
    自雇 / 出租 / 有限纳税义务 管你个人所得税的那个 Finanzamt

    要填的字段（按 02/2026 版）¶

    • 姓、曾用名（Geburtsname）、名
    • 境外地址：街道 + 门牌 / 邮编 + 城市 + 国家 —— 就填中国地址
    • 出生日期、出生地、出生国
    • 目前在德国的停留：Ja（按天 / 短期）或 Nein（如跨境通勤）
    • 德国地址（如有）+ 预计停留期间（起 / 止）
    • 申请原因：Arbeitnehmer（雇员）或 Sonstiger Grund（其他，需文字说明）
    • 雇主名称 + 雇主税号 + 雇主地址
    • 联系电话（Rückfragen）
    • 授权接收人（如雇主）+ 用途（工资税代扣 / 其他）
    • 地点、日期、本人签字

    随附材料¶

    护照或身份证复印件（官方写的是 Kopie，不要求公证）。

    收到方式¶

    IdNr 会邮寄到你填的境外地址；也可以在表里指定由某个人（例如雇主）代收。 不收费。

    三条路线怎么选¶

    你的情况 该用哪张表
    在德国受雇或有有限纳税义务，人住在国内 010250
    只是要提交德国个税申报 不用单独申请，申报过程中税务局会给 IdNr
    境外公司（在德国无固定营业场所）要在德国做应税业务、要 USt-IdNr Fragebogen zur umsatzsteuerlichen Erfassung von im Ausland ansässigen Unternehmern（FsEAusUN） —— 可用纸质，有德 / 英 / 法三语
    在德国设立了公司 / 有固定营业场所 Fragebogen zur steuerlichen Erfassung（034250），必须 ELSTER 电子提交
    完全没有任何德国连接点，只想「挂个德国税号」 走不通。德国不发无连接点的 IdNr

    境外企业那条路（FsEAusUN）要什么¶

    • BMF-Schreiben 2026-07-16 发布新版 Vordruckmuster，自 2026 纳税年度起适用， 德 / 英 / 法三个语种等效

    • 以波恩税局对第三国企业的清单为例，常要：

    • FsEAusUN 表单本体

    • 税收居民证明（Ansässigkeitsbescheinigung）—— 中国这边对应《中国税收居民身份证明》，向主管税务机关申请
    • 公司成立文件（章程 / 注册证书之类）
    • 法定代表人护照复印件
    • 相应附页
    • 同意与税局邮件沟通的声明

    • 填表指南（Ausfüllhilfe）

    • 🔴 附页别漏：附页按业务形态分 —— Körperschaften und Gesellschaften（法人 / 合伙）、Einrichtungen（机构）、 Handel mit Waren über das Internet（通过互联网销售货物）、Personenbeförderung（客运）、 Anteilseigner（股东）。只在网上卖货的境外企业要额外填网络销售那一张。

    容易踩的坑¶

    • 010250 ≠ Fragebogen zur steuerlichen Erfassung，填错表 = 白跑一趟
    • 别信「人在国内也能拿德国税号」的教程：那些讲的几乎都是「在德受雇」或「在德有房租收入」， 把最重要的前提给省略了
    • 只有境内企业那套 100% 电子化；010250 和 FsEAusUN 都还能纸递
    • 德国税局办事用德语（FsEAusUN 提供英法译文，但回复仍是德语）。 语言不通就附一份德语说明信，或委托 Steuerberater（税务顾问）
    • IdNr 不是税务居民证明。它只是内部识别号。 要证明「我是中国税务居民」，出的文件是中国税务机关的《中国税收居民身份证明》； 要证明外国企业的居民身份，出的是对方国家的 Ansässigkeitsbescheinigung
    • IdNr 终身不变、不看地址；Steuernummer 换辖区会变 —— 别拿 Steuernummer 当身份证号用
