# 有了 ITIN 之后：1040-NR 的「零申报」到底怎么做

来源：IRS《Taxation of Nonresident Aliens》、*Instructions for Form 1040-NR (2025)*、
Topic 857、*How to renew an ITIN*、Rev. Rul. 2004-34、IRS 首席律师备忘录
（POSTF-120162-05 / SCAF-138481-04）、IRC §6012(a)(1)(A)、§874(a)、§6651、§6662、§6702。
整理时间 2026-10。

## 先说结论

**「零申报」在美税里对应两个完全相反的东西，一个正常、一个会被罚 $5,000。**

| | **A. 合法的零税申报** | **B.「全零申报」zero return** |
| --- | --- | --- |
| 是什么 | 该报的栏**如实填满**，只是算下来 taxable income / tax = 0 | 收入栏、税额栏统统填 0，其余能省则省 |
| 前提 | 你**本来就有**申报义务 | 无申报义务，或想隐瞒收入 |
| IRS 态度 | 正常受理 | Rev. Rul. 2004-34：*"The zero return position has no merit and is frivolous."* |
| 后果 | 无 | §6702 **罚款 $5,000**（2006 年从 $500 上调），可能叠加 §6651(a)(1) 未申报罚 + §6662 |

🔴 **最贵的误解**：以为「递一张全零的表 = 我在报税 = ITIN 保住了」。

IRS 首席律师备忘录（POSTF-120162-05、SCAF-138481-04）的结论是：
**全零的表缺乏计算税额所需的信息，多数巡回法院认为它不满足 *substantial compliance*，
不构成一份有效的申报表。** 既然不是有效申报，它就**不能算「ITIN 被使用过」** ——
3 年时钟不会因此重置。钱花了、罚挨了、号照样过期。

## 你什么时候「有申报义务」

按 IRS《Taxation of Nonresident Aliens》，非居民外国人在下列任一情况下必须报 1040-NR：

1. **在美国从事（或被视同从事）贸易或业务** —— 哪怕**没有收入**、哪怕收入被协定豁免
2. 没有从事 USTB，但有美国来源收入且**预扣不足**
3. 想**退税**（被多扣了）
4. 代表已故非居民 / 任非居民遗产信托的受托人
5. 承担某些特别税（AMT、HSA 附加税、 household employment tax 等）

第 1 条最反直觉：**「没赚钱也得报」**。法律依据 IRC §6012(a)(1)(A) +
Treas. Reg. §1.6012-1(b)。

⚠️ 持 **F / J / M / Q** 签证的学生、教师、受训者被**视同** engaged in USTB，
所以「有义务」；但仍需**有应税收入**（工资、奖学金应税部分、股息等）才必须报 1040-NR。
纯豁免、无应税收入的 F/J 学生只交 **Form 8843**，不交 1040-NR。

## 合法的「零税」是怎么出来的

三种常见情形，税额自然算成 0，但表是**填满的**：

| 情形 | 怎么填 | 税额 |
| --- | --- | --- |
| 在美工作过，工资被协定豁免（如中美协定教师 / 学生条款） | 收入如实填，豁免部分在 **Schedule OI** 声明，必要时附 **Form 8833** | 0 |
| 美国房产出租，净租金 = 0 或为负 | Schedule E 如实列收支 | 0 |
| 只有被协定豁免的银行利息 | Schedule OI 声明协定条款 | 0 |

🔴 **分水岭就一句**：合法零税申报**不是把栏填成 0，而是把真实数字填进去后算出来是 0**。
前者是申报，后者是废纸。

## 对中国境内、没有美国活动的 ITIN 持有人

说直白些：**你没有申报义务，也就不存在「零申报」这个动作。**

- 没去过美国、没有美国来源收入 → 上面 5 条一条都不触发
- 主动递一张 1040-NR → IRS 不会因为「你有 ITIN」就认为你该报
- 递全零表 → 见上：不构成有效申报，还可能进 Frivolous Return Program

**所以这条路保不住 ITIN。** 保号规则是硬的：

> ITIN 若连续 **3 个纳税年度**未出现在联邦税表上（作为申报人本人，
> 或作为被抚养人列在表上），将在第三个未使用年度之后的 **12 月 31 日**过期。

来源：IRS Topic 857、《How to renew an ITIN》（PATH Act 规定）。
过期后续期仍要走 **Form W-7**，且仍需**联邦纳税目的** —— 不是交钱就能续。

### 如果你确实需要「保住 ITIN」

唯一正当方式是**让它在一次真实申报里被使用**。对国内持有人，最现实的入口是：

| 你有的是什么 | 该报什么 | 结果 |
| --- | --- | --- |
| 美股 / 基金分红被预扣 30% | 1040-NR + **Schedule NEC**，援引中美协定第 9 条股息 10% | 退回多扣的 20%，ITIN 被使用 |
| 被 backup withholding 扣了 **24%** | 1040-NR 申报 + 退税 | 全额或大部分退回 |
| 美国来源的劳务 / 平台收入 | 1040-NR（可能构成 USTB） | 依法申报，别想着报零 |
| 只有一家美国单成员 LLC、无美国经营活动 | **Form 5472 + pro forma 1120**，不报 1040-NR | ⚠️ 信息申报，惯例上**不视为**「使用 ITIN」，别指望它保号 |

⚠️ 最后一行是个常被销售说成「有 LLC 就能养号」的说辞 —— 3 年规则说的是
*federal tax return*，pro forma 1120 是信息申报。稳妥理解是**不重置时钟**，
拿它当保号方案之前找持牌 CPA 确认。

## 实操：真有义务时怎么 DIY

### 时间坐标（重要）

现在是 **2026 年 10 月** —— **2025 税年已经全部过期**（含 4868 延期到 2026-10-15 也已过）。
要报就是 **2026 税年**，表格 2027 年初才发布。

| 你的情况 | 2026 税年截止日 |
| --- | --- |
| 有工资且被美国预扣 | **2027-04-15** |
| 无工资预扣 | **2027-06-15**（法定自动延后） |
| 需要再延 | 4868 表 → **2027-10-15**（延期不延付款） |

### 要准备的材料

- 护照（身份 / 国籍）
- **Form W-2**（工资）、**1042-S**（协定豁免或 FDAP 收入）、**1099-DIV / 1099-INT / 1099-NEC**
- 入出境日期（当年 + 前两年）→ 填 Schedule OI，也用于实质居留测试
- 你援引的**协定条款号**（中美协定：股息第 9 条、利息第 10 条、特许权使用费第 11 条，
  学生 / 教师另有条款）
- 银行账户信息（要退税的话）

### 表格组合

| 表 | 什么时候要 |
| --- | --- |
| **1040-NR** | 主表 |
| **Schedule OI** | **所有** 1040-NR 填报人都要填 —— 漏了是最常见的处理延误原因 |
| **Schedule NEC** | 有 FDAP 收入（股息、利息、特许权使用费）且不属于 ECI |
| **Schedule E** | 有美国房产出租 |
| **Form 8833** | 援引协定条款且金额超过法定门槛时披露协定立场 |
| **Form 4868** | 要延期 |

### 提交方式

- **纸递**：用当年 *Instructions for Form 1040-NR* 里 *Where to File* 的地址。
  2026 年**不随表付款**的纸质表寄 **Austin, TX**。**地址每年变，别抄旧教程。**
- **电子申报**：可以，但**大量消费级报税软件不支持 1040-NR**。
  支持的非居民场景产品：**Sprintax / OLT / TaxSlayer Pro** 等。
- 需要同时递 **W-7**（首次申请或续期）的，**必须纸递**。

## 迟报的代价（比罚款更狠的一条）

| 条款 | 后果 |
| --- | --- |
| §6651(a)(1) | 未申报罚：每月欠税额 5%，上限 25% |
| §6662 | 准确性相关罚：20%（重大漏报 40%） |
| §6702 | 轻率申报罚：**$5,000** |
| 🔴 **§874(a)** | **不申报的非居民将丧失全部扣除和抵免的权利** —— IRS 直接按**毛收入**算税 |

最后一条是 NRA 特有的：迟报不只是加点罚息，是**把你的扣除权拿走**。
所以真有义务时，**主动补报也远好过不报**。

## 决策表

| 你的情况 | 该做什么 |
| --- | --- |
| 纯国内居民、无美国收入、想「养着」ITIN | ❌ **别报**。没有零申报这回事，递全零表会被当废纸甚至重罚。让号自然过期，将来真有需要再走 W-7 |
| 有美股分红被扣 30% | ✅ 报 1040-NR + Schedule NEC，用协定把股息率降到 10%，退回 20% |
| 被 backup withholding 扣 24% | ✅ 报 1040-NR 退税 |
| 在美国工作过 / 学习过（F/J/M/Q） | ✅ 按 USTB 规则报，Schedule OI 必填 |
| 只有美国单成员 LLC、无经营活动 | ⚠️ 报 5472 + pro forma 1120；别指望它养 ITIN |
| 想找中介「包零申报保号」 | 🚩 大概率是递废纸。先问对方：填不填 Schedule OI？报不报身份和协定条款？ |
