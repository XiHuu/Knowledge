# 卡组织与卡等级体系（银联 / Visa / 万事达 / 美国运通）

来源：中国银联开放平台高端卡规范、Visa 与 Mastercard 与 American Express 官网、
中国人民银行公告、第三方公开整理（Trip.com / Money101 / 美国信用卡指南 / FLYERT）。
整理时间 2026-10。

## 一句话

**卡组织定义等级体系和权益平台，具体「你这张卡是哪个等级」由发卡行决定。**
所以同为白金卡，两家银行的权益可以差很远。

## 先分清三件事

| 概念 | 谁决定 | 怎么看 |
| --- | --- | --- |
| **卡组织**（卡别 / 品牌） | 卡面上那个标 | 银联 / Visa / 万事达 / 美国运通 |
| **卡等级**（卡等） | 卡组织定体系，**发卡行给具体卡定级** | 卡面左上角英文：`GOLD` / `PLATINUM` / `DIAMOND` / `SIGNATURE` / `WORLD ELITE` |
| **卡片产品名** | 发卡行 | 「×× 联名白金卡」「学生版」「数字版」 |

**认卡顺序：先看卡组织标 → 再看卡面等级英文 → 最后才看银行给的产品名。**

> ⚠️ 银行产品名里的等级词不一定等于卡组织等级。建行 bilibili 卡就是
> **学生版 = 金卡（卡面印 GOLD）、标准版 = 标准白金卡（印 Platinum）**，
> 两张卡图案一模一样，只差左上角那行字。

## 银联 UnionPay

卡号 **62** 开头。等级从低到高：

| 等级 | 卡面字样 | 门槛 |
| --- | --- | --- |
| 普卡 | （无特殊标识） | — |
| 金卡 | `GOLD` | — |
| **白金卡** | `PLATINUM` / `PRIORITY PLATINUM` | 信用额度通常 **≥ 5 万元** |
| **钻石卡** | `DIAMOND` | 刚性年费 **≥ 5000 元/年**；仅限个人发行 |

- 银联把**白金卡 / 钻石卡**定为「高端卡」，有统一字标规范：
  白金卡卡面**必须**印「Platinum」；钻石卡**必须**印「DIAMOND」且须用银联统一设计的字标
- 权益走**银联权益平台**（绑卡后每月自动领取）：1 元洗车 / 代驾 / 市内停车、
  62 元机场快速安检、机场贵宾厅等
- 等级还能拿去匹配第三方会籍。例：美高梅「美狮荟」——
  钻石卡 → 铂卡会籍、白金卡 → 金卡会籍、金卡 → 银卡会籍、普卡 → 银卡会籍

## Visa

卡号 **4** 开头。等级从低到高：

| 等级 | 中文常见译名 | 说明 |
| --- | --- | --- |
| Classic / Traditional | 普卡 | 有的卡面写 `Visa Platinum`，实质与普卡无差别 |
| Gold | 金卡 | |
| Platinum | 白金卡 | |
| **Signature** | **御玺卡**（台译「御璽卡」） | 中高阶 |
| **Infinite** | **无限卡** | 高阶，有 24 小时「无限秘书」 |
| Infinite Privilege | 无限殊荣卡 | 港 / 加 / 中东有，**大陆和台湾没有** |

- 判等级最直接的办法：**卡面上的 Visa 标旁边会写 `Signature` / `Infinite`**；
  只写「VISA」的就是 Traditional
- 🔴 **美国市场只发到 Signature**（美国不发行 Infinite），所以美卡攻略里的分级和亚洲对不上
- 权益由 Visa 给平台、**发卡行选给哪些**：Signature 起有购买价格保护、退货保护、
  旅行紧急援助、秘书服务；Infinite 在此基础上把同类保障额度提高，
  并把租车险从 Secondary 变成 Primary（出事时**先赔**，不用等你的车险）

## 万事达 Mastercard

卡号 **5** 或 **2** 开头。前三级全球通用，**高端三级看市场**：

| 等级 | 中文 | 说明 |
| --- | --- | --- |
| Standard | 普卡 | |
| Gold | 金卡 | |
| Platinum | 白金卡 | |
| Titanium | 钛金卡 | 亚洲常见，约当 Visa Signature |
| **World** | **世界卡** | 高端 |
| **World Elite** | **世界之极** | 顶级 |
| World Legend | 世界传奇 | 最新最高阶（2025 起，台湾首波锁定高资产客群） |

- 🔴 **命名分市场**：美国只用 Standard / World / World Elite（+ 新的 World Legend）；
  亚洲普遍还有 Gold / Platinum / Titanium
- 权益逐级叠加：World 起有 Lyft 折扣、Mastercard Travel、高尔夫；
  World Elite 加礼宾服务、Priority Pass 贵宾厅；World Legend 再加 Soho House 等

## 美国运通 American Express

卡号 **34 / 37** 开头，**卡号只有 15 位**（比别的组织少一位）。
运通比较特别 —— **它按「产品系列」命名，不是纯按等级**。

经典系列从低到高：**绿卡 Green → 金卡 Gold → 白金卡 Platinum → 百夫长黑金卡 Centurion**

| 产品 | 年费（美国口径） | 定位 |
| --- | --- | --- |
| Green 绿卡 | $150 | 入门 |
| Gold 金卡 | $325 | 餐饮 |
| Platinum 白金卡 | $895 | 旅行；贵宾厅 + 酒店金会籍 |
| **Centurion 百夫长黑金卡** | 约 $5,000（另加一次性入会费约 $10,000） | **仅邀请制** |

- 🔴 **黑卡不能申请**，只能被邀请，运通不公开门槛与细则
- ⚠️ **「百夫长白金卡」≠ 普通「白金卡」**：前者是运通旗舰之一，
  兴业银行年费主卡 6000 元、招商 / 民生 / 工行都有，**且仅限邀约客户申请**

## 中国大陆的四家清算格局（2026-10）

| 卡组织 | 境内清算主体 | 状态 |
| --- | --- | --- |
| 银联 | 中国银联 | 本土主体 |
| 美国运通 | 连通（杭州）→ **运通（上海）银行卡清算有限公司** | **2020-06** 拿证、2020-08 开业；运通持股已超 80%，2026 更名并迁至上海 |
| 万事达 | 万事网联信息技术（北京） | **2023-11-17** 拿证、**2024-05-09** 开业（万事达 51% / 网联 49%） |
| Visa | 威士信息技术（北京） | 🔴 **2026-10-13 获准筹备**，须 1 年内完成筹备，再申请开业 |

🔴 **拿不到境内清算许可证，就不能发该品牌的人民币卡。**

所以到现在为止 **Visa 只能做外币卡的跨境清算**：境内居民持 Visa 外币卡只能在境外用，
境外居民持 Visa 外币卡只能在境内用。等威士公司拿到许可证，境内才会有 Visa 品牌人民币卡。

万事达、运通拿到许可证后，已能发**境内外通用的「中国万事达」/ 美国运通人民币卡**，
且都能绑微信、支付宝、云闪付使用。

## 容易搞混的几点

- **卡等级 ≠ 额度**：额度是发卡行按你的资信综合定的。有人白金卡额度反而比金卡低。
  不过顶级卡核卡门槛通常要求更高额度（如部分银行要求 Visa Infinite 至少给到 $10k）
- **卡等级 ≠ 权益多少**：等级给的是「上限」，具体给哪些由发卡行自行选择
- **等级可以变**：发卡行能给单卡升等 / 降等；也有整批卡被集体转换等级的
- **中文译名不统一**：Visa Signature 大陆叫「御玺卡」、台湾叫「御璽卡」；
  Mastercard World 两岸都叫「世界卡」
- **认等级最快的方法**：看卡面左上角英文，或到发卡行官网该卡的产品页查
  （一般会直接写「卡等级：××」）
