# 银行卡与开户

本分类**按地区组织**，收录各地**银行卡（借记卡 / 信用卡）**与**银行开户**的公开条件、
材料清单、费用对比与实操要点。

> **为什么按地区分而不是按「银行卡 / 信用卡」分**：
> 信用卡本质上就是银行卡的一种，而且开户条件、监管规则、办理渠道
> **都是按地区（司法管辖区）绑定的** —— 同一个地区内的卡和账户才互相可比较。
> 本站其它分类（如税务）同样按地区组织。
