整理时间 2026-10。

## 三条通道

| 通道 | 适用 | 关键限制 |
| --- | --- | --- |
| **手机开户**（中银香港手机银行 App） | 持中国居民身份证的内地居民 | **必须身处香港** |
| **分行开户** | 通用 | 建议预约；热门分行可能拒绝 walk-in |
| **内地见证开户** | 不便赴港者 | 需 **3 个月以上**香港长期签注（留学/工作等） |

## 手机开户（内地居民）

**资格条件**（三个身份类别之一，此处只列内地居民）：

| 项 | 要求 |
| --- | --- |
| 年龄 | 年满 18 岁 |
| 身份 | **全新客户**（未持有任何中银香港个人/联名储蓄、往来账户） |
| 位置 | **身处香港**，且允许 App 读取位置信息 |
| 证件 | 有效**中国居民身份证** + **往来港澳通行证** —— 自申请日起**两证均须有 30 天以上**有效期 |
| 出入境记录 | **国家移民局**发出、**申请日起最近 7 日内**的「出入境纪录」电子档 |
| 联系 | 内地手机号 + 内地地址 + 有效电邮地址 |
| 其他 | 税务居民编号等资料 |

可一站式开立：综合理财服务、港元储蓄账户、外汇宝账户、手机银行及网上银行、中银卡（提款卡）。
无需亲临分行，最快几分钟完成，账户可即时使用。

**常见被拒原因**：

- 未在香港境内，或定位未能确认
- 「出入境纪录」不是国家移民局发出，或**超过 7 日**
- 证件有效期不足 30 天
- 证件拍摄不清、反光，或人脸识别失败
- 已持有中银香港账户（非全新客户）

## 分行开户

**所需文件正本**：

- 身份证明文件 —— 内地居民用：**往来港澳通行证 + 中华人民共和国居民身份证**（或护照）
- **最近三个月的住址证明**

**预约**：官网「预约开立香港账户」页面 → 选「中国居民身份证」+「一般账户」→ 填资料 → 选分行与时段 → 提交，会收到确认电邮（到分行须出示预约编号）。
据第三方对比整理，中银香港**每天 00:00 放号、提前 7 个营业日**放预约。

> 理论上不强制预约，但分行轮候多，热门分行（尖沙咀、铜锣湾、中环等）可能拒绝 walk-in，
> **实务上预约几乎是必要步骤**。

## 内地见证开户

**适用对象**：年满 18 岁，持中华人民共和国居民身份证或中国护照，并已取得
**3 个月以上香港长期签注**（主要为留学、工作等签证；**旅游、商务等短期签证不适用**）。

**流程**：

1. 预约后亲临内地见证网点
2. 携带身份证（或护照）+ 3 个月以上长期签注的往来港澳通行证
3. 在理财经理见证下，接听中银香港 KYC 来电并签署开户文件
4. 账户获批后，下载中银香港手机银行 App 启动账户

> 中行官网另有一条更严的口径：见证开户**只接受中国银行「中银理财」或南商（中国）「南商理财」客户**申请，
> 须亲临**指定**分/支行办理，**不接受他人代办**，文件齐备时手续约**两星期内**完成。
> 两条口径略有差异，**办理前先打热线确认**。

**内地服务热线**：+86 400 800 2388

## 账户级别与「综合理财总值」

中银香港「综合理财服务」分四级，须维持指定的「综合理财总值」（TRB）：

| 级别 | 综合理财总值要求 |
| --- | --- |
| 私人财富 | 港币 800 万 |
| 中银理财 | 港币 100 万 |
| 智盈理财 | 港币 20 万 |
| 自在理财 | 港币 1 万 |
| 港币储蓄 / 往来账户 | 无要求 |

**不达标不会阻止开户**，只是无法享受该级别专属优惠（可能产生月费，见下）。

## 费用（据官方《一般银行服务收费》表）

| 项目 | 收费 |
| --- | --- |
| **服务月费**（港币储蓄/往来账户，每月综合平均结余低于 HK$5,000） | **豁免 —— 且该条注明「只适用于企业客户」** |
| 服务月费（人民币账户每月平均结余少于 RMB5,000） | 豁免 |
| **开户后 3 个月内结清账户** | 往来账户 HK$200／储蓄账户 HK$50 |
| 补发存折 | 每户 HK$100 |
| 注册「转数快」 | 个人客户豁免收费直至另行通知 |

> ⚠️ **个人储蓄账户的低额结存月费是豁免的**。网上流传"2026 年 1 月起中银香港对未达标个人账户
> 重新收取低额结存月费"的说法，与官方收费表正文不符 —— 该条明确限定企业客户。
> 综合理财各**级别**是否另有未达标月费，**请下载官网收费表 PDF 或向客户经理确认**。

## 其他

- 中银香港是香港**三大发钞银行**之一，分行与 ATM 覆盖全港，据对比整理 ATM 数量全港第一
- 提供**人民币储蓄账户**
- 账户开立本身免费
- 联系电话 / 网点：见官网「分行网络」页
