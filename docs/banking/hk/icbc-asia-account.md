## 三条通道

| 通道 | 适用 | 关键限制 |
| --- | --- | --- |
| **内地见证开户** | 境内工行现有客户 | 需 **3 个月以上**香港长期签注 + **留学/外派/务工**目的 |
| **香港柜面开户** | 所有人 | 文件与见证开户相同 |
| **手机银行预填 + 到港激活** | 持内地身份证的全新客户 | 仍需**本人到香港**激活 |

## 通道一：内地见证开户 ★ 要求最明确

### 适用对象（三条同时满足）

1. 年满 **18 岁**
2. **境内居民**，且为**境内工商银行现有客户**
3. 已取得香港**长期签注（三个月以上）**，且以**留学、外派、务工**等长期在境外居留为目的

> ⚠️ **不接受旅游等短期出境客户办理开户见证业务。**
> 官网要求提供留学/外派/务工的**有效证明材料**（包括但不限于录取通知书、外派通知、劳务合同或雇佣协议等）。

### 所需文件（两项必须同时持有）

1. 本人境内**居民身份证**（**不含临时身份证**）
2. 有效**港澳通行证**（含有效签注且**有效期在三个月以上**）
3. 留学 / 外派 / 务工的**有效证明材料**
4. **住址证明**：最近三个月内由**政府机构或公共事务机构**发出的、列有客户姓名及地址数据的账单或信函
   —— **如有效身份证上的地址已可显示当前居住地址，则住址证明可不用提供**

### 流程与时效

1. 到工行柜面填**纸质申请表**，或预先登录工银亚洲门户网站**在线填单**
2. **保存申请单、记录申请单编号**，用 A4 纸**打印申请单**
3. ⏰ **14 天内**携证件到开户见证受理网点办**正式开户手续** —— **逾期所提交资料自动作废，需重新提交申请**
   （赴网点前可随时在网上查询或修改个人资料）
4. 现场获得：**工银亚洲账号、网银／电话银行／银行卡密码信封／电子密码器**
5. 受理网点整理资料发送至工银亚洲
6. 资料审核齐备后，工银亚洲客服中心**致电核实**（身份证号码、地址、电话号码等）
7. 电话确认后**第 2 个工作日**开通网银／电话银行服务
8. **7–10 个工作日**左右收到工银亚洲**快递寄送的银行卡**

**受理网点**：覆盖全国主要省市（北京、天津、河北、山西、内蒙古、辽吉黑、上海、江苏、浙江、安徽、
福建、江西、山东、河南、湖北、湖南、广东、广西、海南、川贵云、陕甘青宁新、重庆、大连、青岛、
深圳、厦门等），另有**华商银行**深圳、广州网点。官网按省份提供 PDF 名单。

## 通道二：香港柜面开户

所需文件与见证开户**相同**。网点地址见工银亚洲官网「分行网络」。

## 通道三：手机银行「全新客户网点开户」

面向**持中国内地身份证的全新客户**：随时通过手机银行预填资料、提交申请，到香港激活。

**材料准备**：

| 项 | 要求 |
| --- | --- |
| 内地身份证正本 | 年满 18 岁，**距证件到期日尚有 100 天或以上** |
| 港澳通行证 / 中国护照正本 | **有效期 100 日或以上**，**签注需在来港开户当天有效** |
| 内地手机号 | 如不在内地，需**开通漫游**以接收短信验证码 |
| 电子邮箱 | 有效地址 |

**流程**：下载工银亚洲手机银行 App →「新客开户」→「中国居民身份证全新客户网点开户 / 立即申请」→
验证手机与电邮 → 拍摄上传身份证及辅助证件 → 填写地址/受雇资料/**开户目的、资金来源、税务信息** →
**预约分行及日期** → 设置网银账号密码 → 手机提供签名 → 提交等待审批（共 13 步，最快 **8 分钟**）。

**预审批通过后**：携**身份证原件、通行证/护照原件、申请时使用的内地手机号、
近三个月内地址证明原件（如有需要）** 按预约日期前往预约网点，完成身份核实并激活账户。

## 账户结构

见证/柜面开立的是 **「理财金账户」** 或 **「综合账户」**，均为含多个子账户的综合账户：

- 港币往来账户、港币储蓄账户
- 外币储蓄账户、定期存款账户
- 美元往来账户
- 人民币往来账户、人民币储蓄账户

> 官网说明：在内地工行网点开立的工银亚洲账户，与直接在香港开立的账户**没有区别**。

## 卡与 ATM

| 场景 | 规则 |
| --- | --- |
| 工行内地 ATM（8 万多台） | **免费**提款及查询已登记账户余额（**不可**改密码、转账或存款） |
| 境内贴「银联」标志的其他银行 ATM | 可查询和提取现金 |
| 香港「银通」(JETCO) 会员 ATM | 提现**免手续费** |
| 澳门 JETCO ATM | 同样支持 |
| 境内/境外贴「银联」标志商户 | POS 刷卡消费 |

**两点要注意**：

1. **海外提款功能默认「未启动」** —— 据香港监管指引，2013-03-01 起工银亚洲所有借记卡和信用卡的
   自动柜员机海外提款功能（含现金透支）均设为"未启动"，在香港以外取款须**预先启动**该功能。
2. **在内地取现有限额** —— 可提取主账户（港币储蓄账户）可用余额；**每天每卡限提等值 2 万港元的人民币**；
   每天取款次数不限，每次上限依各行柜员机设置；提取的人民币按工银亚洲**当日外汇牌价（汇买价）**折算港元扣账。

**启动海外提现功能**：

- 内地：致电 **95588** → 按「7」分行特色及漫游 → 按「7」漫游 → 按「2」海外漫游 → 按「1」银行服务 → 按「0」找客服主任
  （周一至五 9:00–18:00，周六 9:00–13:00）
- 香港：(852) 218 95588 → 按「1」银行服务 → 按「0」
