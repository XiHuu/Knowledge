## 一句话定位

**境内首张以「2」开头的万事达借记卡**，卡号以 **223300** 开头
（前四位 `2233` 正好对应 B 站 22 娘 / 33 娘）。
**人民币单一结算、境内外通用、免年费免账户管理费**，
是「学生也能办」的**高阶境内外通用借记卡**。

## 官方产品信息（中国银行官网原文口径）

| 项 | 说明 |
| --- | --- |
| **产品名称** | **万事达哔哩哔哩2233联名借记卡** |
| 系列 | **全新中国万事达卡系列** |
| 等级 | **普卡** |
| **卡号** | 以「**223300**」开头，**16 位** |
| 有效期 | **6 年** |
| 芯片 | 🔴 **「PBOC + EMV」双应用芯片**（降低境内外伪冒欺诈风险） |
| 卡组织 | **万事达（Mastercard）**；另有**银联版**（卡 BIN **621790**） |

### 申请对象（门槛极低）

> 凡自愿遵守《中国银行股份有限公司长城借记卡章程》并符合个人结算账户开立条件的个人，
> 均可凭人民银行规定的**本人实名制有效身份证件**申领。
> **无需审核资信，且对年龄无特殊限制**（未成年人可由监护人代办申领）。

**——「无需审核资信」这一句，是它对学生/无资产人群最大的意义。**
（借记卡不受学生信用卡那套监管约束，**也不占信用卡的两个「名额」**。）

### 人民币结算（官网原文）

- **境内、境外交易均使用人民币扣款**
- 🔴 **无需提前购汇，不占用购汇额度**
- 境外交易（消费或取现）时**仅支持人民币扣款**（不支持外币），
  具体金额以万事达清算金额为准要求为准

### 全球通用

- 可在标有万事达卡标识的 **POS / ATM / 网站** 上支付、取现
- 覆盖**全球 210 个国家和地区、超 1.6 亿个商户**
- 支持在**微信、支付宝、京东、抖音、美团、滴滴、拼多多、携程、唯品会**等平台快捷支付

### 金融功能

账户管理、本外币存取款、本外币转账汇款、**结汇购汇**、本外币投资理财，
以及外币兑换、跨境汇款、全球账户服务、**中银见证通**、个人留学贷款等跨境金融服务。

## 🔴 费用优惠（官方原文）

> **免收借记卡年费、账户管理费、境内 ATM 查询/取现手续费，
> 2026 年底前免收开卡工本费。**

另有不定期境外消费返现、开卡礼等（以实际情况为准）。
万事达品牌卡权益见万事达「中国万事达」借记卡权益页。

## 办理渠道

### 渠道一：中行网点

凭本人有效身份证件在**中国银行境内营业网点**办理，
**当日申请即可领卡，无需激活便可使用**。

### 渠道二：手机银行 B 站专区**线上预约**（推荐）

1. **中国银行手机银行 → B站专区** → 「借记卡线上预约」
2. 填姓名、身份证号、手机号 → **选择预约网点** → **个性化定制选号** → 提交预约
3. 🔴 提交后预计 **7–15 个工作日**制妥并**邮寄至你指定的领卡网点**
4. 携**身份证等有效证件**前往该网点**领卡开户**

> ⚠️ **预约网点默认显示的未必是离你最近的** —— 提交前**手动改成**方便领卡的网点。

## 🔴 选号规则（这是它最大的乐趣，也是最大的坑）

支持**免费定制卡号后 5–6 位**（申请时必须填 5–6 位数字）。

| 规则 | 说明 |
| --- | --- |
| **无门槛规则** | 后 6 位中**不可出现 3 位及以上重复数字**（不能 `666`、`888`、`000`）。**每个数字重复两次可以**，例如 `223300` |
| **高阶连号** | `6666`、`8888` 等极品连号，或定制超过后 6 位范围 → 需**中银财富管理门槛（日均资产 100 万元及以上）**或一级分行特殊审批 |
| **次数限制** | 🔴 **每天 5 次**查询/刷新机会，**搜索和「换一换」共用次数**，用完只能第二天再试 |
| **次数补救** | 通过 B 站链接申请用完 5 次后，可去**中国银行 App 内「B站专区」**，该入口**额外提供 5 次** |
| **张数限制** | 同一人在同一家银行的借记卡**原则上不超过 4 张**。名下已有 4 张中行借记卡将**无法提交**新卡申请 |

**柜面查完整卡号**：部分前端会脱敏屏蔽，可请柜员用配套查询代码 **`9071123`**
（业务名称：线上预约制卡进度查询）。

### 卡号结构（万事达版，DP）

| 卡段 | 位数 | 说明 |
| --- | --- | --- |
| **卡 BIN** | 第 1–6 位 | `223300` 固定 |
| **地区码** | 第 7–8 位 | 按发卡地区确定（如重庆为 `23`） |
| 中间流水号 | 第 9–10 位 | 校验与顺序分配 |
| **自定义尾号** | 尾部 5–6 位 | 用户输入（须无 3 连号） |

因为**地区码固定**，很多人会优先选与 `2233` / `3322` 呼应的尾号、生日、纪念日或顺子号。
**好号先到先得。**

## 线下办理流程（DP，可给柜员参考）

正常柜面「自选卡号」会触发**集中授权**（要求资产达 100 万）。
但本卡网申支持特定规则选号，柜面已针对本卡做了**无资产门槛选号适配**。

**柜面标准三步：**

1. **`8003319`**（申请预选卡号）—— 输入产品代码（如万事达横版 `501000249`）查询可选卡号
2. **`8003320`**（分配预选卡号到网点）
3. **`8103102`**（开非预制卡）—— **不会触发集中授权**

> ⚠️ **坑一**：若柜员**不做前置预选**而直接用 `8103102` 选号，
> 系统会**强制跳转财富管理集中授权**，导致非达标客户被拒。
> 请礼貌提醒柜员按总行下发的基础选号流程操作。
>
> ⚠️ **坑二**：目前已知 **江苏、陕西等分行**执行 `8003319` 时可能**搜不到卡产品**
> （提示基础选号系统维护中），暂不支持线下选号。
>
> ⚠️ **坑三**：由旧版「上海哔哩哔哩联名借记卡（牡丹亭）」换卡至同 BIN 新版 2233 卡，
> 在部分地区可能出现**系统报错**，建议直接开立新户或咨询当地网点。

## 卡片属性与领卡激活（DP）

- 🔴 **网申卡是「空卡」，申请时不会预开户** —— 激活前**无法对卡片做任何资金操作**
- 卡面统一印刷「**BOC DEBIT**」，**不印制个人拼音姓名**
- 只有网点把卡片**扫描入库**后，后台状态才转为 `04 待领卡`。
  长时间不变动可能是卡已到网点但未及时入库，可联系网点人工核查
- 卡片到达网点后一般**保留 6 个月**（超时后部分网点按预制卡留存，部分按规定销毁）
- **柜面激活**：柜员使用交易代码 **`8103102`**（个人开非预制卡）。
  🔴 激活时请**核对卡号**，确保与申请时的自选卡号一致

### 进度查询与状态码

进入预约页面 → 底部「申请进度查询」→ 输入信息查询。

| 状态码 | 含义 |
| --- | --- |
| `00` | 待制卡（已提交申请） |
| `01` | 制卡中 |
| `03` | 寄送中 |
| `04` | **待领卡**（卡片已寄达网点并完成入库） |
| `06` | 已领卡 |
| `02` / `05` / `07` | 流程异常 |

## 用卡：一类 vs 二类

- 一家银行**只能有一个一类账户**
- 若你已有中行一类卡且**不降级原账户**，这张联名卡**大概率只能是二类卡**
- **领卡时工作人员会问你要开一类还是二类** —— 提前想好

## 🔴 激活后境外在线支付（DP，否则会扣款失败）

激活后若要在境外网站（Steam、各类订阅服务等）在线支付，
**必须在中国银行 App 中手动开启：**

- **小额免密**
- **磁条支付**
- **电子支付**

否则会导致**扣款失败**。

**汇率与冻结比例**：境外在线支付采用万事达官方实时汇率，
交易入账前通常有 **102% 的预授权冻结比例**
（多出的 2% 为汇率波动保证金，**清算结算后退回**）。

## 优缺点小结

**优点**

- ✅ **无需审核资信、对年龄无特殊限制** —— 门槛极低，学生可办
- ✅ **境内外通用、人民币结算、无需购汇、不占购汇额度**
- ✅ **免年费、免账户管理费、免境内 ATM 查询/取现手续费**，2026 年底前免工本费
- ✅ **2233 卡号前缀**有纪念意义，卡面好看，**可免费选号**
- ✅ 借记卡**不受学生信用卡监管约束，也不占信用卡的两个名额**

**缺点 / 注意**

- ⚠️ 等级只是**普卡**，金融权益并不突出
- ⚠️ **境内线下受理不如银联**（万事达受理点虽在扩张，但仍少于银联）
- ⚠️ **网申只能拿到竖版**；横版需线下开非预制卡（部分分行系统不支持）
- ⚠️ 老户/已有中行一类卡 → **大概率只能开二类**
- ⚠️ 选号**每天 5 次**，好号先到先得，**别随手乱点**
