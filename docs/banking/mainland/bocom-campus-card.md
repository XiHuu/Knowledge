## 以下为停发前的产品资料（存档参考）

### 一句话定位

停发前它曾是**申请路径最明确、在校期间零年费**的学生卡，卡面选择极多，
免境内溢缴款取现及转账手续费。

### 申请资格

官网「校园卡仅限在校大学生申请」页面口径：

| 项 | 要求 |
| --- | --- |
| 身份 | **仅限在校大学生**（教育部认可高校的**专科、本科、研究生及以上**学历在校学生） |
| 年龄 | **18 – 35 周岁** |
| 其他 | 需授权银行查询个人征信；**非二代身份证客户须至线下网点办理** |

申请入口为校园卡专用端口（`creditcardapp.bankcomm.com/applynew/front/apply/campus/`），
也可通过**买单吧 App → 所有卡产品 → 学生专属**进入。
不同主题卡面额度一致，差别在权益和卡面。

### 年费与费用

| 项目 | 收费 |
| --- | --- |
| 年费 | **80 元/年，在校期间免年费** |
| 工本费 | **0 元**（核卡后自动从卡内扣除） |
| 境内溢缴款取现 | **免手续费** |
| 境内溢缴款转账 | **免手续费** |
| 免息期 | 最长 **56 天** |

> ⚠️ 「在校期间免年费」≠ 永久免年费。毕业后是否计收 80 元/年，需向交行确认。

### 额度

**零额度银联卡。** 第三方早期标注「参考额度 0–2 千」，但 iidawnlight 的整理明确写为
**零额度银联卡**，此前部分卡板有**运通人民币版**（后来没有了）。
申请时会给**监护人发送短信**落实第二还款源，并要求**上传本人及监护人户口簿对应页**，
并**直接提供「毕业转卡」途径**。

**学生信用卡产品不支持加办外币卡。**

### 权益（停发前）

- **积分**：微信 / 支付宝 **1 元积 1 分**（部分卡面）
- **最长 56 天**免息还款期
- **最红星期五**：在买单吧 App 领取并激活秒减额度后，每周五在指定便利店享秒减 50%、
  指定超市及加油站秒减 5%，同一持卡人每月总计可秒减 100 元
  - 持有校园卡主卡且在校期间的持卡人，**无需满足上月消费门槛**即可激活按月使用
- **卡面可更换**：通过「买单吧」App 可定制 Y-POWER 系列部分卡面，**无需更换卡号**
- 部分卡面有**新户首刷礼**（如 90 元券包）

### 卡面（数量极多，曾经是它最大的卖点）

- **Y-POWER 系列**：原力黑、活力白、Y-POWER 燃主题
- **12 生肖系列**：鼠牛虎兔龙蛇马羊猴鸡狗猪 + 总领
- **洛天依系列**：横版、一剑霜寒、虎虎生V、十周年纪念版、知交逍遥、依见倾心、洛舞樱花
- **鬼灭之刃系列**：交锋版、守护版、开运版、进取版、全员版
- **校园高达主题卡（夏亚）**
- **银联饿了么普卡（校园版）**
- **银联剑侠情缘叁校园卡**：游戏内充值享 **2 倍积分**
- **校庆 / 院校专属**：苏州大学 120 周年校庆、宁夏大学主题卡等

### 申请流程（停发前）

1. 校园卡专用申请页，填姓名 / 身份证 / 学校所在城市
2. 依次完成：初步审核 → 信息填写 → 提交成功
3. 需勾选同意：征信查询授权、敏感个人信息处理授权书、服务许可协议、
   小额免密免签（免费，推荐勾选）
4. 有一项可选授权值得勾：**「如无法核发申请的卡片等级，同意以实际批核结果为准
   自动核发其他等级卡产品」** —— 页面标注可提高审批通过率

### 第二还款来源

按监管要求，学生卡发卡前**必须落实第二还款来源**。交行流程中会要求填写
**家长 / 直系亲属的电话与身份证信息**，并向监护人发短信；
部分地区要求上传**本人及监护人户口簿对应页**。

## 现在还能怎么办

交行学生卡停发**不代表没有替代**：

- 想要**真实额度** → 看 [中信校园 i 卡](citic-campus-i.md) 或
  [建行 bilibili 学生版](ccb-bilibili-campus.md)
- 只想**外币消费 / 累积征信** → 走**借记卡**或**直系亲属附属卡**，
  见 [学生信用卡总览](student-cards-overview.md) 第七节
- 交行**在职卡**仍在发行 —— 毕业后可正常申请
