# 中国大陆银行卡总览

本目录收录**中国大陆可办的银行卡**，分两条线：

- **信用卡** —— 主要是**学生信用卡**（0 门槛那批，受监管约束）
- **借记卡** —— **境内外通用的借记卡**（不受学生信用卡监管限制，是学生实际更好走的路）

按地区导航总入口见 [银行卡与开户](../index.md)。

---

## 一、学生信用卡（0 门槛）

> 监管前提：《商业银行信用卡业务监督管理办法》规定
> **向同一申请人核发学生信用卡的发卡银行不得超过两家（附属卡除外）**，
> 且发卡须事前落实**第二还款来源**。详见总览页。

## 二、境内外通用借记卡

> 🔴 **为什么借记卡更值得看**：
> **借记卡不受学生信用卡那套监管约束**（没有「两家名额」、不需要第二还款来源），
> **也不占信用卡名额**，所以对没有资产/收入的学生更实际。
>
> 代价是**先存后花**，没有透支额度。

| 页面 | 卡组织 | 一句话 |
| --- | --- | --- |
| [招商银行 万事达人民币 IC 借记卡](cmb-mastercard.md) | 万事达 | **零门槛**，但🔴**只能网点办，不支持网申** |
| [中信银行 美国运通人民币借记卡](citic-amex-debit.md) | 美国运通 | **App 可申请、可邮寄**，15 位卡号 |
| [中国银行 哔哩哔哩 2233 联名借记卡](boc-bilibili-2233.md) | 万事达（也可银联） | 🔴 **卡号 223300 开头 + 免费选号**，学生也能办 |
| [招商银行 哔哩哔哩花嫁联名储蓄卡](cmb-bilibili-card.md) | 银联 | 想要 B 站卡面 + 一张好用借记卡 |

### 这三张「境内外通用借记卡」怎么选

| 你的情况 | 建议 |
| --- | --- |
| 想**全程线上搞定、不想跑网点** | **中信银行美国运通人民币借记卡**（App 申请可邮寄） |
| 想**要 2233 卡号前缀 + 选号** | **中国银行 2233 联名卡**（但选号有 5 次/天的限制，想清楚再点） |
| 想**去网点办、要免费** | **招商银行万事达人民币 IC 借记卡**（零门槛，记得 VTM 搜 `WSD`） |
| 只想要**好看的卡面** | 招行 **哔哩哔哩花嫁联名储蓄卡** |

**共享的三条共同逻辑：**

1. 🔴 **人民币清算、不用购汇、不占个人年度购汇便利化额度** ——
   这是它们相对「银联卡 + 提前购汇」的核心价值
2. 🔴 **借记卡不受学生信用卡监管约束**，也不占那两家银行的名额
3. ⚠️ **境内线下受理不如银联广**（万事达/运通受理点都在扩张，但仍少于银联）

## 三、还不占名额的两条替代路线

如果学生信用卡名额已满，或信用审核过不了：

1. **办借记卡**（上面那三张）—— **完全不受学生信用卡监管约束**
2. **办直系亲属的附属卡** —— 监管明确「**附属卡除外**」，**不占名额**；
   额度随主卡，代价是**消费对主卡人可见**

详见 [学生信用卡总览](student-cards-overview.md) 的替代方案一节。
