# 交通银行 校园卡 / Y-POWER 校园版

来源：交行信用卡官网校园卡申请页（`creditcardapp.bankcomm.com/applynew/front/apply/campus/`）、
交行活动页细则、第三方卡片资料。整理时间 2026-10。

## 一句话定位

**目前申请路径最明确、在校期间零年费的学生卡**，卡面选择极多，免境内溢缴款取现及转账手续费。

## 申请资格

官网「校园卡仅限在校大学生申请」页面写明：

| 项 | 要求 |
| --- | --- |
| 身份 | **仅限在校大学生**（教育部认可高校的**专科、本科、研究生及以上**学历在校学生） |
| 年龄 | **18 – 35 周岁** |
| 其他 | 需授权银行查询个人征信；**非二代身份证客户须至线下网点办理** |

> 申请页有独立入口（校园卡专用端口），**不同主题卡面额度一致，差别在权益和卡面**。

## 年费与费用

| 项目 | 收费 |
| --- | --- |
| 年费 | **80 元/年，在校期间免年费** |
| 工本费 | **0 元**（核卡后自动从卡内扣除） |
| 境内溢缴款取现 | **免手续费** |
| 境内溢缴款转账 | **免手续费** |
| 免息期 | 最长 **56 天** |

> ⚠️ "在校期间免年费" ≠ 永久免年费。**毕业后是否开始计收 80 元/年，需向交行确认。**

## 额度

第三方卡片资料标注：**参考额度 0 – 2 千**（银联普卡、人民币）。

额度是浮动的，最终以交行审批为准。这条也意味着**它属于"可能有小额真实额度"的一类**，
而不是纯 0 额度先存后花。

## 权益

以当前在售卡面为例（权益随活动变动，以官网为准）：

- **积分累积、优惠同享** —— 微信/支付宝 **1 元积 1 分**（部分卡面）
- **最长 56 天免息还款期**
- **最红星期五**：活动期间在买单吧 App 领取并激活秒减额度后，每周五可在指定便利店享秒减 50%、
  指定超市及加油站秒减 5%，**同一持卡人每月总计可秒减 100 元**
  - 名下持有校园卡主卡且在校期间的持卡人，**无需满足上月消费门槛**，可直接激活按月使用
- **卡面可更换**：通过「买单吧」App 可定制 Y-POWER 系列部分卡面，**无需更换卡号**
- 部分卡面有**新户首刷礼**（如 90 元券包），以活动页为准

## 申请入口与流程

1. 官网校园卡专用申请页（`creditcardapp.bankcomm.com/applynew/front/apply/campus/index.html`）
2. 填姓名 / 身份证 / 学校所在城市
3. 依次完成：初步审核 → 信息填写 → 提交成功
4. 申请页需勾选同意：征信查询授权、敏感个人信息处理授权书、服务许可协议、
   小额免密免签（免费，推荐勾选）
5. 有一项可选授权值得勾：**「如无法核发申请的卡片等级，同意以实际批核结果为准自动核发其他等级卡产品」
   —— 页面标注可提高审批通过率**

## 第二还款来源

按监管要求，学生卡发卡前**必须落实第二还款来源**。交行申请流程中会要求填写
**家长/直系亲属的电话与身份证信息**（第三方申请指引记录）。

> 具体要谁签、要不要到场，各行各地网点执行不一，**以申请时的页面和网点要求为准**。

## 注意

- 交行学生卡产品历史上**停发过一次**（第三方整理称 2023-01 疑似停发），**2023-07 重新开放申请**。
  → 产品状态会变，申之前先确认申请页还能不能进、还能不能提交。
- 早期交行学生卡有 VISA 版，**后来停掉，目前基本是银联单币**。
- 校园卡有独立的活动与权益体系，**部分优惠仅限"在校期间"**，毕业前后差异要看细则。
