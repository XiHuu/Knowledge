# 学生信用卡总览（中国大陆 · 0 门槛 / 0 年费）

整理时间 2026-10。来源：各行官网产品页与申请页、官方公告、监管文件，以及第三方 Data Point（已标注）。
监管原文见银保监会/人民银行公开通知与《商业银行信用卡业务监督管理办法》。

> ⚠️ 学生信用卡是**变动最频繁**的一类产品：停发、重开、零额度化、页面下线都常见。
> 第三方 DP（网友实测记录）**可能已过时**。申卡前务必以银行官网/App/网点当时的说法为准。
> 本文不构成任何建议。

## 先搞清"0 开"是哪一种 0

这个词在不同语境下指四件不同的事，别混：

| 说法 | 含义 | 典型例子 |
| --- | --- | --- |
| **0 门槛** | 无资产、无收入、无工作也能申请 | 学生卡基本都算 |
| **0 年费** | 免年费，且**不靠刷卡次数**换 | 中信校园 i 卡（无条件免年费）、交行校园卡（在校期间免） |
| **0 额度** | 先存款后消费，**没有可透支额度** | 招行校园版、浦发校园版（DP：无提额途径） |
| **0 工本费** | 制卡费 0 元 | 交行校园卡（核卡后从卡内扣除 0 元） |

**"0 额度"和"有额度"是两回事** —— 这是学生卡最核心的区别，下面会反复出现。

## 两条监管硬约束（决定你能办几张、要谁签字）

这不是银行的规定，是监管规定，所有银行都得守：

### ① 发卡前必须落实"第二还款来源"

- 银监会 2009《关于进一步规范信用卡业务的通知》第六条：**不得向未满 18 周岁的学生发放信用卡**（附属卡除外）。向**已满 18 周岁、无固定工作、无稳定收入来源**的学生发卡，**须落实第二还款来源**，该方须具备偿还能力，且**必须书面同意承担还款责任**，否则不得发卡。
- 银保监会 2022《关于进一步促进信用卡业务规范健康发展的通知》第（十二）条再次明确：**银行业金融机构发放学生信用卡，应当事前落实第二还款来源。**

**实操形态**：申请表上多一页 —— **家长/监护人（或直系亲属）的姓名、身份证号、电话**，本人需同意承担还款责任。
有银行还会要求第二还款来源人**到场**或**签署承诺书**。

### ② 最多只能有【两家银行】给你发学生卡

- 《商业银行信用卡业务监督管理办法》：**向符合条件的同一申请人核发学生信用卡的发卡银行不得超过两家（附属卡除外）。**

🔴 **这是最容易被忽略、也最容易浪费机会的一条。** 银行的征信查询能看出你在别家有没有学生卡。
**持有两家银行的学生卡后再申第三家，大概率被拒。** 而且这个额度是"名额"，不是"申请次数"。

> **推论**：选卡顺序必须**先想清楚**再动手。别随手申请一家不想要的，把名额浪费掉。

## 现状：大部分银行已经没有学生卡业务

据长期维护该话题的第三方整理（idawnlight，最后更新 2025-09）：

> "目前大部分银行已无学生信用卡业务，仅存的学生信用卡产品**大多默认无授信额度**。"

原因很直观：监管严格 + 学生客群利润有限 + 睡眠卡考核压力（2022 年通知要求长期睡眠卡占比不得超 20%）。

## 怎么选（考虑"两家银行"的限制）

推荐顺序 —— **先确定目的，再决定给哪两家**：

1. **想要真实可透支额度** → 优先看**中信校园 i 卡**（但要先查你的学校在不在官网名单里）
2. **想要免年费 + 消费权益 + 卡面可换** → **交行校园卡**（在校期间免年费，卡面极多）
3. **只想提前累积征信、毕业转卡** → **招行校园版**（0 额度先存后花，毕业转卡提额）—— 但先确认现在还发不发
4. **想拿境外用卡（留学/考试报名）** → 看双币卡，注意外币兑换费

> 💡 **别急着一次性申完两家。** 先把目标产品的在售状态和学校名单查清楚，
> 再决定用掉哪两个名额。

## 通用避坑

1. **先查学校名单**。中信校园 i 卡官网明写"目前仅支持列表中学校申请，非列表中学校提交申请将无法批核"。
2. **别隐瞒学生身份去申在职卡**。这是违规操作，被查到会销卡 + 影响征信。
3. **"无条件免年费"要看清楚**。很多卡写"免年费"其实是"刷 6 次免次年"——要刷卡次数才免的**不算无条件**。
4. **0 额度卡的额度是封存的，不是没有**。招行校园版的额度"毕业前暂时封存"，毕业转卡后会释放更高额度。
5. **睡眠卡会拖累你**。2022 年监管要求银行清理长期睡眠卡（连续 18 个月无主动交易且余额为零），
   占本行发卡量超 20% 的银行**不得新增发卡** —— 这也是银行不愿给学生发卡的原因之一。
   不用的卡（尤其是白占"两家名额"的）**及时销户**。
6. **销户也要走完流程**并销毁芯片磁条，别随手丢。
7. **警惕"包过"中介**。学生卡申请本身免费，任何收费代办都要怀疑。
