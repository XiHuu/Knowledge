# 适马 fp → fp2：六年后换掉了什么

> 发布于 2026-10-23。fp2 是 2019 年初代 fp 的第二代，**不是** fp L 的继任者——fp L 那条 6100 万像素的高像素支线目前仍在售。

## 一句话结论

fp2 没有改产品思路，只是把初代被诟病的短板逐条补上：**传感器换成部分堆栈式、视频从 4K 跳到 6K 开门、加了翻折屏和机身内存、电池换成松下的通用型号**。机身反而比初代更薄。

## 逐项看，真正有用的升级

**1. 部分堆栈传感器是这次的核心。**
初代的痛点是反差对焦和果冻效应，根子都在读出速度。换成部分堆栈后，读出变快，连带解决了三件事：追焦能跟上动体、20 fps 连拍有实用缓冲、果冻效应被压低。像素几乎没变（24.6 → 24.5MP），说明适马没走堆像素的路。

**2. 6K 开门（Open Gate）。**
按整块 3:2 传感器录制，而不是先裁成 16:9。好处是后期可以自由重构成横版、竖版或任意比例而不掉画质——这是给多平台分发准备的，不是为了 6K 本身。

**3. 翻折屏终于有了。**
初代固定屏被骂了六年。fp2 在机身反而变薄 3.5 mm 的前提下塞进了上翻 90° / 下翻 45° 的翻转结构，这是工程上比表面看起来难的地方。

**4. 电池换成松下的。**
BP-91 与松下 DMW-BLK22 同款，意味着副厂电池、充电器、假电池供电的生态直接通用。对影视用户来说，这比"续航 +30%"更实在。

**5. 70 GB 机身内存。**
比 SD 卡快，也能在卡满或卡坏时兜底。严格说是锦上添花，但在这种小机身里算实在。

## 需要泼冷水的地方

- **32-bit 浮点音频不是原生能力**。要另买 HU-21 热靴单元，再接松下的 XLR 适配器，配件栈加起来的价格和体积都不算小。
- **仍然没有内置取景器**。EVF-21 是外接件，单买一套 $2,699 起；想要大取景器还有 LVF-21，但会把机身撑得很大，和"最小全画幅"的初衷相悖。
- **模组化路线没变**：手柄（HG-11）、热靴（HU-21）、底板、充电器、AC 供电口全是要另买的。裸机 $2,199 不是可用配置的价格。
- **官方规格表没有列机身防抖**。前两代 fp 都没有 IBIS，fp2 目前也未见相关说明，依赖镜头防抖或稳定器。
- **早期传闻不准**。发布前有报道称 fp2 会"内置电子取景器"，实际是外接 EVF-21——EVF 进机身这件事并没有发生。

## 谁该换

- **值得换**：拍了六年 fp、被反差对焦和固定屏卡住的视频用户；需要 6K 开门做竖版/多平台分发的创作者。
- **不必换**：以静态摄影为主、已经接受 fp 慢对焦的人；预算敏感者——初代二手价格会是 fp2 的零头。
- **要另看**：需要高像素的看 fp L（6100 万），需要机身防抖的这本就不是 fp 系列的选项。
